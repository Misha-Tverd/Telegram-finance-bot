# Telegram Finance Bot

Telegram Finance Bot - це простий бот для ведення сімейного або особистого бюджету в Telegram. Він допомагає записувати доходи та витрати, вести баланс, планувати витрати на поточний місяць і дивитися статистику по місяцю та року.

## Можливості

- Запис витрат по категоріях.
- Запис доходів по категоріях.
- Автоматичне оновлення балансу після кожної операції.
- Кнопка швидкого відкладання 10% від доходу в заощадження.
- Планування витрат на поточний місяць для всіх категорій.
- Статистика витрат за місяць: фактичні витрати і план.
- Статистика витрат за рік: фактичні витрати і план.
- Пошук операцій за датою.
- Видалення записів з перерахунком балансу та статистики.
- Зберігання даних у локальній SQLite базі.

## Встановлення

1. Відкрийте папку проекту:

```bash
cd Telegram-finance-bot
```

2. Створіть віртуальне середовище:

```bash
python -m venv .venv
```

3. Активуйте його.

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Windows CMD:

```cmd
.\.venv\Scripts\activate.bat
```

macOS/Linux:

```bash
source .venv/bin/activate
```

4. Встановіть залежності:

```bash
pip install -r requirements.txt
```

## Налаштування Telegram-бота

1. Відкрийте Telegram і знайдіть `@BotFather`.
2. Створіть нового бота командою `/newbot`.
3. Скопіюйте токен, який видасть BotFather.
4. У файлі `bot/main.py` знайдіть рядок:

```python
API_TOKEN = "..."
```

5. Вставте свій токен замість поточного.

Важливо: не публікуйте справжній токен у GitHub або інших відкритих місцях. Якщо токен уже потрапив у публічний репозиторій, перевипустіть його через BotFather командою `/revoke`.

## Запуск

Запустіть бота командою:

```bash
python bot/main.py
```

Після запуску відкрийте свого бота в Telegram і натисніть `/start`.

## Як користуватися ботом

### Головне меню

Після команди `/start` бот показує основне меню:

- `💸 Витрати`
- `💰 Дохід`
- `🗓 Витрати на місяць`
- `📊 Статистика`
- `🏦 Баланс`
- `🔍 Пошук/Видалити`

### Додавання витрати

1. Натисніть `💸 Витрати`.
2. Оберіть категорію, наприклад `Продукти`, `Комунальні`, `Транспорт`.
3. Введіть суму.

Можна ввести тільки число:

```text
250
```

Або суму з описом:

```text
молоко і хліб 250
```

Бот збереже запис, зменшить баланс UAH і покаже кнопку для скасування запису.

### Додавання доходу

1. Натисніть `💰 Дохід`.
2. Оберіть категорію доходу.
3. Введіть суму.

Після запису доходу бот запропонує кнопку `Відкласти 10%`. Якщо натиснути її, 10% від доходу буде перенесено в заощадження.

### План витрат на місяць

Кнопка `🗓 Витрати на місяць` запускає заповнення плану на поточний місяць.

Бот по черзі показує всі категорії витрат. Для кожної категорії потрібно ввести планову суму:

```text
5000
```

Якщо по категорії в цьому місяці витрат не планується, введіть:

```text
0
```

План зберігається окремо по місяцях. Коли настане новий місяць, бот створюватиме і показуватиме дані вже для нового періоду.

### Статистика

Натисніть `📊 Статистика`, після цього оберіть:

- `📅 Витрати за місяць`
- `📆 Витрати за рік`

У статистиці бот показує:

- фактичні витрати;
- заплановані витрати;
- розбивку по категоріях.

Приклад логіки:

```text
Продукти: факт 3200.00 / план 5000.00 грн
Комунальні: факт 1500.00 / план 2000.00 грн
```

### Баланс

Кнопка `🏦 Баланс` показує поточний стан рахунків:

- UAH
- USD
- EUR
- COINS
- SAVINGS

Доходи збільшують баланс, витрати зменшують його. Видалення запису перераховує баланс назад.

### Пошук і видалення записів

1. Натисніть `🔍 Пошук/Видалити`.
2. Введіть дату у форматі:

```text
2026-04-27
```

3. Бот покаже записи за цей день.
4. Біля кожного запису буде кнопка видалення.

Після видалення бот оновлює баланс і статистику.

## База даних

Проект використовує SQLite базу `bot/finance.db`.

Основні таблиці:

- `journal` - всі доходи та витрати.
- `balances` - поточні баланси рахунків.
- `monthly_expense_plans` - планові витрати по місяцях і категоріях.
- `monthly_category_totals` - підсумки по категоріях за місяць.
- `yearly_category_totals` - підсумки по категоріях за рік.

Таблиці створюються автоматично під час запуску бота.

## Формат дат і періодів

- Дата операції записується автоматично в день створення запису.
- Формат дати: `YYYY-MM-DD`.
- Місячна статистика використовує формат `YYYY-MM`.
- Річна статистика використовує формат `YYYY`.

## Налаштування користувачів

У `bot/main.py` є словник:

```python
USER_MAP = {
    847387368: "Міша",
    854570254: "Настя",
}
```

Він прив'язує Telegram user ID до імені користувача. Якщо ID немає в списку, бот записує користувача як гостя.

## Примітки для розробки

- Основна логіка знаходиться у `bot/main.py`.
- Клас `FinanceDB` відповідає за роботу з SQLite.
- Клас `UI` відповідає за кнопки меню.
- Стани введення описані в `FinanceStates`.
- Бот працює через polling: `dp.start_polling(bot)`.

## Типові проблеми

### ModuleNotFoundError: No module named 'aiogram'

Потрібно встановити залежності:

```bash
pip install -r requirements.txt
```

### Бот не відповідає в Telegram

Перевірте:

- чи запущено `python bot/main.py`;
- чи правильний `API_TOKEN`;
- чи немає іншого процесу з тим самим ботом;
- чи є інтернет-з'єднання.

### Не створились нові таблиці в базі

Таблиці створюються під час запуску `bot/main.py`. Якщо файл бази старий, просто запустіть бота ще раз після оновлення коду.
